LocalFlix（完全ブラウザ版）
============================

起動方法
--------
1. index.html をダブルクリックします。
2. Chrome または Edge で開きます。
3. 右上の「フォルダを追加」を押し、対象フォルダを選びます。
4. 対象を増やす場合は、右上の「フォルダを追加」を繰り返します。

Python、start.bat、インストールは不要です。

主な機能
--------
- 初期の並び順は「おすすめ順」。端末の日付ごとにランダム風の並びになり、同じ日・同じファイルでは再選択やページ再読み込みでも同じ順序になります。
- おすすめ順で開いたまま日付をまたいだ場合、約30秒以内（休止中はタブに戻ったとき）に一覧を更新します。動画の追加・削除時も既存動画同士の順序は維持します。
- サブフォルダを含む動画ファイルの一覧表示
- 複数の動画フォルダをまとめて表示
- 追加済みフォルダの個別解除
- 動画からのサムネイル自動生成
- サムネイル右下に動画の再生時間を表示
- マウスを重ねた動画を無音でプレビュー
- クリックすると、再生画面を広めに取った2ペイン表示に切り替え
- 動画を再生しながら一覧の検索・スクロール・選択が可能
- 分割モードとシアターモードの切り替え
- 再生中は約1.5秒操作がないと上部ボタンが消え、マウス操作などで再表示します。一時停止中は表示します。
- 再生画面右上のループアイコンで繰り返し再生を切り替えます。白い背景がオンで、設定は次回も記憶します。
- 分割モードの中央のハンドルを左右へドラッグして幅を変更できます。幅はブラウザに記憶し、ダブルクリックで初期幅に戻せます。ハンドルを選択して左右キーでも調整できます。
- ページを開いて最初に再生するときは常に分割モード
- シアターモードでは再生画面をほぼ1画面分の大きさで表示
- プレイヤーは固定せず、下へスクロールすると代表シーン、通常の動画一覧の順に表示
- シアターモードの動画一覧も通常と同じ複数列グリッド表示
- 動画から代表シーンを自動抽出し、画像クリックでその時刻へ移動
- シーン画像から移動したときは再生画面まで自動スクロール
- シーン画像は常に同じサイズで表示し、分割モードでは複数列に折り返して再生パネル内を縦スクロール可能
- 各動画カードの下にも小さな代表シーンを3枚表示
- シーン画像の取得・読み込みに失敗した場合も、同じサイズの代替表示で3枠を維持
- 動画名で検索。フォルダは専用のプルダウンで指定でき、「すべてのフォルダ」も選べます。指定フォルダのサブフォルダも含みます。
- 一覧の小さなシーン画像をクリックすると、その動画の該当時刻から再生します。
- おすすめ順・名前・更新日時・再生時間を選び、横の「昇順／降順」ボタンで順序を切り替え。初期状態はおすすめ順・昇順です。
- 更新日時は昇順で古い順、降順で新しい順。再生時間は昇順で短い順、降順で長い順。おすすめ順も日ごとの並びを反転します。
- 再生時間はフォルダ読み込み後、ソート項目に関係なくバックグラウンドで取得します。取得済みの時間は次回にも利用します。取得できない動画は再生時間順では末尾に表示します。
- 昇順・降順はソート横の矢印アイコンで切り替えます。マウスを重ねると現在の順序を確認できます。
- 検索、並び替え、フォルダ操作はスクロールしても残る上部バーに集約
- 対象フォルダ一覧は上部のフォルダ名から開くメニューに収納
- 動画本数と合計サイズも上部バーに表示し、一覧先頭の位置ずれを防止
- フォルダ未選択時は右上の「フォルダを追加」から選択
- 前回選んだ複数フォルダの記憶（ブラウザが対応している場合）

注意点
------
- Chrome / Edge の最新版を推奨します。
- ブラウザの安全機能により、初回は必ずフォルダを選ぶ必要があります。
- 前回のフォルダが記憶されていても、再起動後にアクセスの再許可が必要な場合があります。その場合は右上の「↻」を押してください。
- MP4でもコーデックによっては再生できません。MP4（H.264/AAC）やWebMが比較的安定します。
- MKV、AVIなども一覧には表示しますが、サムネイル生成・再生の可否はブラウザの対応状況によります。
- シーン画像は動画全体から等間隔に抽出した代表場面です。内容を解析して重要場面を判定する機能ではありません。
- 一覧用のシーン画像は、画面に近い動画から2本ずつ処理するため、表示まで少し時間がかかる場合があります。
- 動画ファイルをインターネットへ送信する処理はありません。

ヘッダーの右上の矢印で折りたたみ／展開できます（状態を記憶）。
通常時の検索と絞り込みはヘッダー内の1行に表示します。狭い画面ではヘッダーを横スクロールできます。折りたたむと上端の小さな展開ボタンだけを残し、一覧と再生に画面を広く使えます。長いフォルダ名は省略し、マウスを重ねると全文が表示されます。

フォルダ絞り込みの幅は175px固定です。ヘッダーの折りたたみ／展開ボタンは同じ小さなタブ形状です。

ヘッダーの小・中・大でサムネイルサイズを変更できます（初期は中、選択を記憶）。シーン画像は一定サイズです。画像の読み込み中や失敗時もシーン枠をクリックすると該当位置から再生します。時刻未取得時は再生動画の長さが分かってから位置を計算します。

サムネイルサイズはヘッダーの3つのアイコンボタンで選択。小は180px・シーン2枚、中は300px・4枚、大は440px・6枚を基準に並びます。シーン枠はカード幅を均等に使います。検索欄は140pxに制限し、時間取得の進捗を独立表示します。

シーン画像は全サイズ共通の幅54pxです。小2枚＝カード112px、中4枚＝228px、大6枚＝344px（間隔4px）。カードは横に引き伸ばしません。検索欄は220〜280px、取得進捗は総数の下に表示。ヘッダー開閉タブは下端に配置します。

最新のサイズ設定：シーン画像は共通で幅72px。小は2枚・カード148px、中は3枚・224px、大は4枚・300pxです。

ヘッダーは高さ72pxに統一。フォルダ名と動画総数を同じ段、取得進捗をその下に配置します。ヘッダーを閉じても一覧の上下左右の余白は維持します。

カード幅は小148px・中224px・大300pxを基準に、余った横幅を各列に均等配分します。シーン画像は幅72px・2/3/4枚を維持し、間隔を均等に調整します。

シーン画像もカード幅に合わせて均等に伸縮します。小2枚・中3枚・大4枚、画像間隔4px、縦横比16:9を維持します。

ヘッダーのフォルダ表示・動画総数・時間取得進捗は横1行の固定枠です。進捗が空でも枠を維持します。フォルダ権限が必要と判定された場合は保存済みの開閉設定を変更せずヘッダーを表示し、権限が必要な間は折りたたみません。

検索からフォルダ追加までの操作UIをひとつのグループとして右寄せに配置します。

動画が見つからない場合や検索中の案内は、総数・取得進捗の表示枠をまとめて使い、全文を1行で表示します。ヘッダー全体の幅と高さは維持します。

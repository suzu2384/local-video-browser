# LocalFlix

PC内の動画を、サムネイル付きの一覧から探して再生するローカル動画ブラウザです。
HTML・CSS・JavaScriptを `index.html` にまとめているため、サーバー、Python、インストール、ビルドは不要です。動画を外部へ送信する処理はありません。

## 起動方法

1. このリポジトリの `index.html` をPCに保存します。
2. `index.html` をChromeまたはEdgeで開きます。
3. ヘッダー右側の「フォルダを追加」で動画のあるフォルダを選びます。
4. 一覧のサムネイルをクリックすると再生します。

複数フォルダを対象にする場合は「フォルダを追加」を繰り返してください。
各フォルダのサブフォルダも再帰的に読み込みます。

## フォルダの管理と検索

- フォルダ選択のプルダウンには、「すべてのフォルダ」と、収集対象として追加したフォルダだけが表示されます。
- 追加したフォルダを選ぶと、その直下だけでなく、すべてのサブフォルダ内の動画も対象になります。サブフォルダを個別に追加する必要はありません。
- サブフォルダ自体はプルダウンに自動追加されません。別途「フォルダを追加」で登録した場合は、独立した収集対象として表示されます。
- 検索欄では動画のファイル名を検索します。フォルダ選択と組み合わせて絞り込めます。
- ヘッダー左側のフォルダ表示を開くと、登録済みのフォルダを確認・解除できます。解除してもPC上の動画は削除されません。
- 動画を追加・削除したあとは、更新ボタン「↻」で再スキャンします。

例えば「動画」というフォルダを登録した場合、「動画/旅行/2026」にある動画も、「動画」を選ぶだけで検索・表示できます。

### フォルダの記憶とアクセス許可

対応するブラウザでは、追加したフォルダを記憶し、次回起動時にも読み込みます。
アクセス許可が必要な場合は、ヘッダーの「↻」を押して再許可してください。

フォルダの記憶を利用できない環境では、フォルダ選択による一時的な読み込みに切り替わります。その場合は、次回起動時にフォルダを選び直します。追加・削除したファイルを反映する際も、一時登録したフォルダを解除して選び直してください。

## 一覧の表示

- 動画からサムネイルを生成し、右下に再生時間を表示します。
- カードには動画名、フォルダ、ファイルサイズを表示します。
- マウスを重ねると、その動画を無音でプレビューします。
- ヘッダーの3つのサイズボタンで、一覧の表示サイズを変更できます。初期設定は「中」で、選択を記憶します。

| サイズ | カード幅の基準 | カード下のシーン画像 |
| --- | --- | --- |
| 小 | 148px | 2枚 |
| 中 | 224px | 3枚 |
| 大 | 300px | 4枚 |

カードは表示領域の余った幅を均等に使って伸縮します。シーン画像もカード幅に合わせて伸縮し、縦横比16:9と画像間隔4pxを維持します。

### 並び替え

ソートのプルダウンで項目を選び、その右の矢印ボタンで昇順・降順を切り替えます。
初期設定は「おすすめ順・昇順」です。

| 項目 | 昇順 | 降順 |
| --- | --- | --- |
| おすすめ順 | 日付ごとに決まるランダム風の並び | その並びを反転 |
| 名前 | 名前順（フォルダを含むパスで比較） | 逆順 |
| 更新日時 | 古い順 | 新しい順 |
| 再生時間 | 短い順 | 長い順 |

おすすめ順は端末の日付を基準にし、同じ日・同じファイル情報なら再読み込みしても同じ並びになります。
日付が変わると、約30秒以内、または休止していたタブに戻ったときに更新します。

再生時間はフォルダ読み込み後にバックグラウンドで取得します。再生時間順で表示している場合は、取得に合わせて並びを更新します。時間が取得できない動画は、昇順・降順のどちらでも末尾に表示します。

## 再生とシーン移動

再生・一時停止、シーク、音量などは、ブラウザ標準の動画操作UIを使います。

### 分割モード

- ページを開いて最初に再生するときは分割モードです。
- 動画を再生しながら、横の一覧を検索・スクロールできます。
- 再生領域と一覧の境界を左右にドラッグすると幅を変更できます。変更した幅は記憶します。
- 境界のダブルクリックで初期幅に戻します。境界を選択して左右キーでも調整できます。
- 再生領域のシーン画像は折り返して表示し、パネル内を縦にスクロールできます。
- 狭い画面では再生領域と一覧が上下に並びます。

### シアターモード

再生画面上部のモード切替ボタンで変更します。
動画をほぼ1画面分の大きさで表示し、下へスクロールするとシーン画像、その下に通常のグリッド形式の動画一覧が続きます。再生画面はページと一緒にスクロールします。

### 再生画面上部のボタン

- モード切替、ループ、閉じるボタンを配置しています。
- 再生中に約1.5秒操作がないとフェードアウトします。マウスが再生領域から外れたときは、すぐにフェードアウトが始まります。
- マウスを再生領域に戻すと再表示します。キーボードで選択中のボタンは表示を維持します。
- ループボタンは白い背景がオンの状態です。設定は次回も記憶します。

これらのボタンの表示制御は、ブラウザ標準のシークバーとは独立しています。

### シーン画像

- 再生中の動画は、長さに応じて5・7・9枚の代表シーンを抽出します。
- 再生領域のシーン画像や、一覧のカード下のシーン画像をクリックすると、その位置へ移動して再生し、再生画面までスクロールします。
- カード下のシーン画像は、読み込み中や取得に失敗した場合も枠を維持し、クリックで該当位置へ移動できます。時刻が未取得なら、再生時に動画の長さを読み取って位置を計算します。
- シーンは動画全体から等間隔に選んだ場面です。内容を解析して重要な場面を判断する機能ではありません。
- シークバー上にマウスを重ねて画像を表示するプレビュー機能は、現在はありません。

## ヘッダー

フォルダ表示・動画本数・合計サイズ・再生時間取得の進捗を横1行に表示します。
進捗が表示されていない間も枠を確保し、操作UIの位置が動かないようにしています。

検索、フォルダ選択、ソート、昇順・降順、サムネイルサイズ、更新、フォルダ追加は、1つのグループとして右側に配置しています。
狭い画面ではヘッダー内を横スクロールできます。

ヘッダー下端の小さなタブで折りたたみ・展開を切り替えます。
折りたたむと画面上端にタブだけが残り、一覧の余白を保ったまま表示領域が広がります。

開閉状態は記憶します。ただし、フォルダのアクセス許可が必要な場合は、保存した設定を変更せずにヘッダーを表示し、許可が必要な間は折りたためません。

## 保存される情報

ブラウザ内の保存領域が利用できる場合、次の情報を保存します。

- 登録したフォルダへの参照
- サムネイルと取得済みの再生時間
- サムネイルサイズ、分割幅、ループ設定、ヘッダーの開閉状態

動画本体をアプリ側へコピーする処理はありません。ブラウザの保存データを削除すると、設定やキャッシュも失われます。
シーン画像のキャッシュはページを開いている間だけ保持します。

## 対象ファイルと制限

一覧への収集対象となる拡張子は次のとおりです。

`mp4`、`m4v`、`webm`、`ogv`、`ogg`、`mov`、`mkv`、`avi`、`wmv`、`mpg`、`mpeg`、`m2ts`、`mts`、`ts`、`3gp`、`flv`

一覧への表示と、実際に再生できるかどうかは別です。再生・サムネイル生成・シーン抽出の可否は、ブラウザと動画のコーデックに依存します。
一覧の画像は画面に近い動画から順に生成するため、本数が多い場合は表示まで時間がかかります。

このアプリが読み込むのは、操作している端末で選択・許可したフォルダです。別の端末からPC内の動画を配信・閲覧する機能や、動画URLの登録機能はありません。

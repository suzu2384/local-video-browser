# LocalFlix

PC内の動画を、サムネイル付きの一覧から探して再生するローカル動画ブラウザです。
HTML・CSS・JavaScriptを `index.html` にまとめているため、サーバー、Python、インストール、ビルドは不要です。動画を外部へ送信する処理はありません。

## 起動方法

1. このリポジトリの `index.html` をPCに保存します。
2. `index.html` をChromeまたはEdgeで開きます。
3. 最初の「フォルダを追加」で、対象フォルダの共通の親となる**基準フォルダ**を選びます。
4. もう一度「フォルダを追加」を押し、基準フォルダ内の収集対象を選びます。基準フォルダ自体も選べます。
5. 一覧のサムネイルをクリックすると再生します。

複数フォルダを対象にする場合は「フォルダを追加」を繰り返してください。
各フォルダのサブフォルダも再帰的に読み込みます。

## フォルダの管理と検索

- フォルダ選択のプルダウンには、「すべてのフォルダ」と、収集対象として追加したフォルダだけが表示されます。
- 追加したフォルダを選ぶと、その直下だけでなく、すべてのサブフォルダ内の動画も対象になります。サブフォルダを個別に追加する必要はありません。
- サブフォルダ自体はプルダウンに自動追加されません。別途「フォルダを追加」で登録した場合は、独立した収集対象として表示されます。
- 検索欄では動画のファイル名を検索します。フォルダ選択と組み合わせて絞り込めます。
- ヘッダー左側のフォルダ表示を開くと、登録済みのフォルダを確認・解除できます。解除してもPC上の動画は削除されません。
- 動画を追加・削除したあとは、更新ボタン「↻」で再スキャンします。
- 対象フォルダをすべて正常に読み込めたら、フォルダのポップアップを自動で閉じます。アクセス許可やフォルダの設定が必要な場合は案内を残します。フォルダやタグのメニューは、領域外のクリックでも閉じられます。

例えば「動画」というフォルダを登録した場合、「動画/旅行/2026」にある動画も、「動画」を選ぶだけで検索・表示できます。

### URLで一覧を分ける

対象を追加・解除すると、URLの `#folders=...` に相対パスの一覧が入ります。そのURLをブックマークすると、対象フォルダの組み合わせを再度開けます。対象を変更したあとは、必要に応じてブックマークも更新してください。

- 例：基準フォルダが `D:\Videos`、対象が `旅行/2026` と `ゲーム` なら、URLにはこの2つの相対パスが入ります。基準フォルダ自体を対象にした場合は `.` になります。
- パスは区切り文字を統一し、重複を除き、並べ替えてからJSONをBase64urlで符号化します。同じパスの組み合わせなら、追加順に関係なく同じURLになります。暗号化ではなく、URLから相対パスを復元できます。
- 基準フォルダへの参照は、URLの組み合わせごとにブラウザ内へ保存します。異なる組み合わせの一覧は、それぞれ別の基準フォルダを使い、別タブで開けます。
- 同じ相対パスの組み合わせは同じ一覧として扱います。その組み合わせに対して別の基準フォルダを選ぶと、次回から使う基準フォルダも更新されます。
- フォルダ表示を開くと、基準フォルダの選択・変更や「別の一覧を開く」が利用できます。新しい一覧では基準フォルダを選び、対象を追加してください。
- URLにはフォルダの絶対パス、動画本体、アクセス許可は含めません。検索語・ソートなどの表示条件も現段階では含めません。

### 別環境での復元とアクセス許可

同じURLを別のPCやブラウザで開いたときは、必要な相対パスを画面に表示します。その構成が入っている基準フォルダを選び直すと、対象を復元します。OSのフォルダ選択画面・許可ダイアログ自体には独自の案内を追加せず、アプリ側に案内を表示します。

記憶した基準フォルダへのアクセス許可が必要な場合は、「↻」またはフォルダ表示内の「アクセスを許可・更新」を押してください。許可や基準フォルダの選択が必要なときは、折りたたみ設定を保持したままヘッダーを表示します。存在しない対象パスはURLに残し、読み込めない旨を案内します。

URLによる復元は、File System Access APIに対応するPC版Chrome / Edgeを対象としています。保存領域が使えない場合は次回に基準フォルダを選び直してください。フォルダ参照に対応しないブラウザでは、URL情報のない状態に限り、一時的なフォルダ選択を利用できます。この場合は再起動時やファイル変更時に選び直してください。

### 以前の登録フォルダからの移行

`#folders=...` のないURLでは、以前の登録フォルダを引き続き読み込みます。「フォルダを追加」またはフォルダ表示内の基準フォルダ選択から、登録済みフォルダをすべて含む共通の親を選ぶと、相対パスへ変換してURLに反映します。旧設定は残るため、URLの `#` 以降を削除すれば以前の登録一覧を開けます。

別ドライブなど、共通の基準フォルダを選べない場合は一覧を分けてください。URL形式へ移行した直後は、サムネイルや再生時間を再取得する場合があります。

## タグの種類の管理

ヘッダーの「タグ」を開き、「解除」の隣の「管理」でタグ名を入力して追加できます。登録済みタグの「✕」で削除します。タグ名は前後の空白を除いた1〜40文字、最大100個です。同名の重複登録はできません。

タグの種類はURLの `tags` パラメータへBase64urlで保存し、そのURLを開くと復元します。追加順によらず同じ種類の組み合わせなら同じ情報になります。変更後はURLをブックマークし直してください。フォルダ情報のない状態でもタグを登録できます。

タグの変更で基準フォルダの記憶は変わりません。タグだけを変更した場合や、ブラウザの戻る・進むでタグだけを戻した場合は、動画の再読み込みや再生の停止を行いません。タグ情報のない従来のURLでは、タグ未登録として開きます。

### タグのカテゴリ

「実況：モンハン」「実況：ディビジョン2」のように登録すると、絞り込み・動画のタグ編集・タグ管理で「実況」の下に項目をまとめます。全角 `：` と半角 `:` のどちらも区切りとして使えます。最初の区切りだけを使い、カテゴリ名と項目名の表示上の前後空白を除きます。区切りがないタグや、左右どちらかが空のタグは通常のタグとして表示します。

URL・割り当て・書き出しでは元のタグ名をそのまま保持します。全角・半角の区切りが違うタグ名は別タグです。カード上も識別できるよう元のタグ名を表示します。

カテゴリのチェックで配下のすべてを選択・解除できます。一部だけ選択している場合はカテゴリのチェックが中間状態になります。カテゴリ自体が新しいタグとして保存されるわけではありません。

絞り込みは**同じカテゴリ内はOR、異なるカテゴリ間はAND**です。例えば「実況」をまとめて選ぶと「実況：モンハン」「実況：ディビジョン2」のどちらかを持つ動画が対象になります。さらに「特徴：面白い」を選ぶと、その中から「特徴：面白い」も持つ動画だけを表示します。

カテゴリのない「お気に入り」「未視聴」などは、それぞれ独立したAND条件です。両方選ぶと両方のタグが必要になります。選択していないカテゴリは条件に含めません。

### 動画へのタグ付け

各カードの「タグ」から、登録済みの種類をチェックして付け外しできます。複数選択でき、変更は自動保存します。タグ編集・タグ管理のダイアログは外側をクリックして閉じられ、反映済みの変更は維持します。登録前の入力中のタグ名は自動追加せず、追加ボタンで登録します。カード下部に付けたタグを表示します。編集しても再生中の動画は切り替わりません。ヘッダーのタグ絞り込みから、複数のタグを条件にして探せます。

割り当てはURLに含めず、ブラウザ内に保存します。基準フォルダごとに分け、基準フォルダからの相対ファイルパスで動画を識別します。同じ基準フォルダで対象を追加・解除しても割り当てを引き継ぎます。フォルダやファイルを改名・移動すると別の動画として扱い、同じパスのファイルを置き換えた場合はタグを引き継ぎます。旧形式の一覧では登録フォルダごとの保存となり、URL形式への移行時は書き出し・読み込みで移してください。

タグの種類を削除すると、その種類の割り当ては非表示になります。割り当て自体は残り、同名の種類を再登録すると表示されます。保存できない環境では一時的に保持し、画面に案内します。

### タグで絞り込む

ヘッダーの「タグ」を開き、チェックで複数選択します。**カテゴリ内はOR・カテゴリ間はAND**で絞り込み、カテゴリのないタグはそれぞれ必須条件になります。名前検索・対象フォルダの指定ともANDで組み合わせられます。未選択ならタグのない動画も含めて表示します。

選択中はヘッダーの「タグ」が白く点灯し、「解除」でタグ条件だけをまとめて外せます。候補が0本になってもチェックは維持されます。タグの付け外し・割り当ての読み込みも一覧に即時反映します。絞り込みから外れた動画も、再生中ならそのまま再生を続けます。

絞り込み条件はURLやブラウザの保存領域には保存しません。ページの再読み込み・対象フォルダの変更時に解除します。タグの種類を削除した場合、その種類の絞り込み条件も外れます。

### 割り当てのエクスポート・インポート

ヘッダーの「タグ」→「管理」から「割り当てを書き出す」「割り当てを読み込む」を使います。

- 書き出し：現在読み込んだ一覧全体（検索・フォルダ絞り込み前）の、登録中の種類が付いた動画をJSONで保存します。動画本体・絶対パス・アクセス許可は含みません。
- 読み込み：現在の一覧と相対ファイルパスが一致する動画へタグを追加します。既存の割り当ては消さずに結合し、不足するタグの種類もURLへ追加します。変更後のURLはブックマークし直してください。
- 見つからない動画や同名の収集フォルダなどで区別できないパスはスキップし、件数を表示します。別環境では先に同じ相対構成の基準フォルダを選び、動画一覧を読み込んでください。
- ファイルは10MB、100,000件までです。形式不正・未定義タグ・重複パスは反映前に検証します。

## 一覧の表示

- 動画からサムネイルを生成し、右下に再生時間を表示します。
- カードには動画名とタグを表示します。フォルダ名・ファイルサイズの行を省き、高さを抑えています。動画名・タグ行の余白とカード間の縦間隔も詰め、行が余分に引き伸ばされない配置にしています。
- マウスを重ねると、その動画を無音でプレビューします。
- カードを選んで再生すると、レイアウト変更後のカードがヘッダーに隠れず画面内に収まるよう、必要な分だけスクロールします。画面が低い場合はサムネイル画像を優先します。シーン画像のクリック時は従来どおり再生画面へスクロールします。
- ヘッダーの3つのサイズボタンで、一覧の表示サイズを変更できます。初期設定は「中」で、選択を記憶します。

| サイズ | カード幅の基準 | カード下のシーン画像 |
| --- | --- | --- |
| 小 | 148px | 2枚 |
| 中 | 224px | 3枚 |
| 大 | 300px | 4枚 |

カードは表示領域の余った幅を均等に使って伸縮します。シーン画像もカード幅に合わせて伸縮し、縦横比16:9と画像間隔4pxを維持します。

### 並び替え

ソートのプルダウンで項目を選び、その右の矢印ボタンで昇順・降順を切り替えます。
初期設定は「おすすめ順・昇順」です。

| 項目 | 昇順 | 降順 |
| --- | --- | --- |
| おすすめ順 | 日付ごとに決まるランダム風の並び | その並びを反転 |
| 名前 | 名前順（フォルダを含むパスで比較） | 逆順 |
| 更新日時 | 古い順 | 新しい順 |
| 再生時間 | 短い順 | 長い順 |

おすすめ順は端末の日付を基準にし、同じ日・同じファイル情報なら再読み込みしても同じ並びになります。
日付が変わると、約30秒以内、または休止していたタブに戻ったときに更新します。

再生時間はフォルダ読み込み後にバックグラウンドで取得します。再生時間順で表示している場合は、取得に合わせて並びを更新します。時間が取得できない動画は、昇順・降順のどちらでも末尾に表示します。

## 再生とシーン移動

再生・一時停止、シーク、音量などは、ブラウザ標準の動画操作UIを使います。

### 分割モード

- ページを開いて最初に再生するときは分割モードです。
- 動画を再生しながら、横の一覧を検索・スクロールできます。
- 再生領域と一覧の境界を左右にドラッグすると幅を変更できます。変更した幅は記憶します。
- 境界のダブルクリックで初期幅に戻します。境界を選択して左右キーでも調整できます。
- 再生領域のシーン画像は折り返して表示し、パネル内を縦にスクロールできます。
- 狭い画面では再生領域と一覧が上下に並びます。

### シアターモード

再生画面上部のモード切替ボタンで変更します。
動画をほぼ1画面分の大きさで表示し、下へスクロールするとシーン画像、その下に通常のグリッド形式の動画一覧が続きます。再生画面はページと一緒にスクロールします。

### 再生画面上部のボタン

- モード切替、ループ、閉じるボタンを配置しています。
- 再生中に約1.5秒操作がないとフェードアウトします。マウスが再生領域から外れたときは、すぐにフェードアウトが始まります。
- マウスを再生領域に戻すと再表示します。キーボードで選択中のボタンは表示を維持します。
- ループボタンは白い背景がオンの状態です。設定は次回も記憶します。

これらのボタンの表示制御は、ブラウザ標準のシークバーとは独立しています。

### シーン画像

- 再生中の動画は、長さに応じて5・7・9枚の代表シーンを抽出します。
- 再生領域のシーン画像や、一覧のカード下のシーン画像をクリックすると、その位置へ移動して再生し、再生画面までスクロールします。
- カード下のシーン画像は、読み込み中や取得に失敗した場合も枠を維持し、クリックで該当位置へ移動できます。時刻が未取得なら、再生時に動画の長さを読み取って位置を計算します。
- シーンは動画全体から等間隔に選んだ場面です。内容を解析して重要な場面を判断する機能ではありません。
- シークバー上にマウスを重ねて画像を表示するプレビュー機能は、現在はありません。

## ヘッダー

フォルダ表示・動画本数・合計サイズ・再生時間取得の進捗を横1行に表示します。
進捗が表示されていない間も枠を確保し、操作UIの位置が動かないようにしています。

検索、フォルダ選択、ソート、昇順・降順、サムネイルサイズ、更新、フォルダ追加は、1つのグループとして右側に配置しています。
ウィンドウ幅に応じて操作UIを複数行へ折り返します。検索欄やフォルダ欄の幅も調整し、ヘッダーの横スクロールは使いません。ソート項目と昇順・降順ボタンは同じ組として配置します。ヘッダーの高さが変わっても再生領域やポップアップの位置は追従します。

ヘッダー下端の小さなタブで折りたたみ・展開を切り替えます。
折りたたむと画面上端にタブだけが残り、一覧の余白を保ったまま表示領域が広がります。

開閉状態は記憶します。ただし、フォルダのアクセス許可が必要な場合は、保存した設定を変更せずにヘッダーを表示し、許可が必要な間は折りたためません。

## 保存される情報

ブラウザ内の保存領域が利用できる場合、次の情報を保存します。

- 一覧のURLごとの基準フォルダへの参照、および移行前の登録フォルダへの参照
- 動画ごとのタグ割り当て
- サムネイルと取得済みの再生時間
- サムネイルサイズ、分割幅、ループ設定、ヘッダーの開閉状態

動画本体をアプリ側へコピーする処理はありません。ブラウザの保存データを削除すると、設定やキャッシュも失われます。
シーン画像のキャッシュはページを開いている間だけ保持します。

## 対象ファイルと制限

一覧への収集対象となる拡張子は次のとおりです。

`mp4`、`m4v`、`webm`、`ogv`、`ogg`、`mov`、`mkv`、`avi`、`wmv`、`mpg`、`mpeg`、`m2ts`、`mts`、`ts`、`3gp`、`flv`

一覧への表示と、実際に再生できるかどうかは別です。再生・サムネイル生成・シーン抽出の可否は、ブラウザと動画のコーデックに依存します。
一覧の画像は画面に近い動画から順に生成するため、本数が多い場合は表示まで時間がかかります。

このアプリが読み込むのは、操作している端末で選択・許可したフォルダです。別の端末からPC内の動画を配信・閲覧する機能や、動画URLの登録機能はありません。
